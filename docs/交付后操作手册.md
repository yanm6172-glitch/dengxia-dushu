## 二、日常改动后上传 GitHub（核心三步）

每次改了代码或文档，在 PowerShell 里执行：

```powershell
cd D:\help\dengxia-dushu
git add -A
git commit -m "改动说明（如：修复xx/新增xx）"
git push origin main
```

> 推送失败（连接被重置）时：隔 1 分钟再执行 `git push origin main` 即可，GitHub 连接抖动是常态，本地提交不会丢。

**提交信息规范**（建议）：
- 功能：`v18 新增xx功能`
- 修复：`修复 打开失败问题`
- 文档：`docs 更新使用说明`

## 三、从零上传一个新项目到 GitHub（换电脑/新项目用）

1. **装 Git**：https://git-scm.com/downloads
2. **配置身份**（首次）：
   ```powershell
   git config --global user.name "你的GitHub用户名"
   git config --global user.email "你的邮箱"
   ```
3. **创建仓库**：登录 github.com → 右上角 + → New repository → 填名称（如 `my-new-project`）→ Create
4. **本地初始化并上传**：
   ```powershell
   cd 你的项目目录
   git init -b main
   git add -A
   git commit -m "首次提交"
   git remote add origin https://github.com/你的用户名/my-new-project.git
   git push -u origin main
   ```
5. 第一次 push 会弹浏览器授权登录 GitHub（Git Credential Manager 自动处理）

## 五、常用 Git 速查

| 操作 | 命令 |
|---|---|
| 看状态 | `git status` |
| 看提交历史 | `git log --oneline` |
| 撤销未提交的改动 | `git checkout -- 文件名` |
| 撤销最近一次提交（保留改动） | `git reset --soft HEAD~1` |
| 打版本标签 | `git tag v1.0.0 && git push origin v1.0.0` |
| 拉取远端更新 | `git pull origin main` |

## 七、常见问题

- **push 报「Connection was reset」**：网络问题，重试即可；连续失败可挂代理后重试
- **忘记提交了什么**：`git status` + `git diff` 查看
- **想彻底重来仓库**：删除 `.git` 文件夹后按「三、从零上传」重做
- **小程序包超 2MB**：优先删内置书或启用分包（参考 README 常见问题节）
