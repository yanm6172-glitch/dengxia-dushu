# 「灯下读书」小程序上线清单

## 1. 注册账号
- [ ] 打开 https://mp.weixin.qq.com 注册小程序（个人主体免费）
- [ ] 完善基本信息：名称（建议「灯下读书」，注意查重）、头像（可用 ui_preview 里的截图裁剪）、简介（如：公版古籍阅读与读书打卡工具）
- [ ] 服务类目建议：「工具 > 效率」或「图书」；涉及书籍内容按平台要求补充说明（全部为公版古籍，无版权风险）

## 2. 平台合规配置
- [ ] **用户隐私保护指引**（审核必查）：公众平台「设置 → 服务内容声明 → 用户隐私保护指引」填写
  - 收集信息：微信头像、昵称（用户主动授权）
  - 用途：展示个人资料；阅读数据仅本地/账号内使用
- [ ] 使用云开发则**无需配置服务器域名**；自建后端才需要配置 request 合法域名（HTTPS）

## 3. 代码准备
- [ ] `project.config.json` 中 `appid` 换成自己的 AppID
- [ ] （可选）云开发：工具内点「云开发」开通 → 上传 `cloudfunctions/login`、`cloudfunctions/sync` → 数据库建集合 `readers` → `services/auth.js` 的 `USE_CLOUD` 改为 `true`
- [ ] （可选）订阅消息：公众平台选模板 → 模板 ID 填入 `services/remind.js` → 云函数加定时触发器推送
- [ ] 开发者工具点「上传」，版本号 v1.0.0，备注写清本次功能

## 4. 提审
- [ ] 公众平台「版本管理 → 开发版本 → 提交审核」
- [ ] 审核辅助说明可写：内容全部为公版古籍（来源：古腾堡计划/国学导航等），登录仅获取头像昵称，无 UGC 内容
- [ ] 若驳回：按驳回意见修改 → 重新上传 → 重新提审（常见驳回点：隐私指引缺失、类目不符、页面功能不完整）

## 5. 发布
- [ ] 审核通过 → 「发布」→ 全量上线，微信内搜索小程序名即可使用
- [ ] 生成小程序码，分享给同学

## 6. 上线后
- [ ] 数据观察：云开发控制台看调用量（免费额度足够个人使用）
- [ ] 迭代：每次改动上传新版本号，附更新说明
- [ ] 备份：源码文件夹 `F:\新建文件夹 (2)\读书小程序` 定期备份到网盘/Git
