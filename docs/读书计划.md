# 大三读书计划（2026–2027 学年）

> 主题：提升自身发展涵养。配套书单说明见同目录《书单说明.md》。

## 一、总原则

1. **每天 25 分钟古籍日课**：出声读 + 圈点批注，不求快（睡前最佳）
2. **每月 1 本主读精读书**：周末 2 小时整块时间，读两遍 + 写 300–500 字笔记
3. **随翻书**：碎片时间翻，读多少算多少，不设进度压力
4. **期末月（1 月、6 月）减量**：只读轻薄书，复习优先
5. **每本书都有输出**：笔记 / 摘抄 / 思维导图 / 书评，任选一种

## 四、读书方法

- **古籍日课**：出声读、断句、圈点生字；注疏版先读大字经文，不懂再看注
- **精读两遍法**：第一遍通读划线；隔几天第二遍只读划线处 + 写笔记
- **输出即消化**：每本主读书至少写 300 字；攒起来就是自己的成长档案
- **读不进去就换**：备选书池顶上，不硬啃——涵养是长出来的，不是熬出来的
