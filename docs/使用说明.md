# 读书小程序「灯下读书」使用说明

## 项目位置
`F:\新建文件夹 (2)\读书小程序\`

## 三步跑起来

1. **安装微信开发者工具**（官方下载）
   https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. **打开工具 → 微信扫码登录 → 「导入项目」**
   - 目录选择：`F:\新建文件夹 (2)\读书小程序`
   - AppID：默认已填 `touristappid`（游客模式，可直接在模拟器里跑）；想真机预览或发布，改成自己的小程序 AppID（个人可免费注册，或用工具里的「测试号」）
3. **编译运行**：模拟器里点任意一本书的「立即读书」即可开始阅读

## 功能清单
- 首页「每日一句」+ 大按钮「立即读书」，直达对应书目
- 书单按「四书 / 修身 / 道家 / 兵家 / 诗文 / 笔记」分类，共 20 本公版古籍
- 每本书卡片有「立即读书」按钮；读过的书显示进度条并变为「继续读书」
- 阅读页：A- / A+ 调字号（4 档）、夜间模式、目录跳转（自动识别卷/篇/章标题）
- 进度自动保存（滚动 2 秒后落盘），重进自动恢复上次位置
- 自动清理古腾堡英文版权头，长篇按句断段

## 项目结构
```
读书小程序/
├── app.json / app.js / app.wxss    全局
├── pages/index/                    书架页（每日一句 + 书单）
├── pages/reader/                   阅读页
├── utils/books.js                  书库登记表（加书改这里）
├── utils/quotes.js                 每日一句语料
├── books/                          主包 13 本（<1.2MB）
└── pkg1/books/                     分包 7 本（<1.8MB）
```

## 加新书的方法
1. 把 txt 文件放进 `books\`（小书）或 `pkg1\books\`（大书）
2. 在 `utils\books.js` 的 `list` 里加一条：
   `{ id: 'xxx', title: '书名', author: '作者', category: '修身', file: '/books/xxx.txt', pkg: 'main' }`
3. 注意：微信要求**主包 ≤ 2MB、单个分包 ≤ 2MB、总包 ≤ 20MB**，大文件优先放 pkg1

## v7 修复：无法打开文章
- **根因**：`readFile` 读代码包文件时，不同基础库对路径格式要求不一致（有的接受 `/books/x.txt`，有的只认相对路径 `books/x.txt`），此前只写了一种格式导致部分环境打开失败
- **修复**：改为多路径变体依次尝试（带/不带前导斜杠），任一成功即可；分包书先加载分包、失败降级直读
- 顺带修复：长行中并入的章节标记（●卷一）重新拆分，论语注疏等书的目录恢复正常；大文件改为分批渲染（首屏 800 段，其余渐进追加），避免 setData 过大卡顿
- 打开失败弹窗现在会显示失败的文件路径，方便继续排查
## v8 修复：彻底解决「无法打开文章」
- **根因**：`FileSystemManager.readFile` 读代码包文件在部分环境（含游客模式/部分开发者工具版本）不可用，试了带斜杠与不带斜杠两种路径都失败
- **方案**：不再依赖文件系统。20 本书正文用 deflate+base64 压缩进 `data/books_data.js`（2.9MB → 1.6MB），`require` 加载 + pako 解压，任何环境必然可读；主包总 1.7MB，合规
- **验证**：Node 全量回归 20/20 通过（30,585 段，最慢解压 74ms）
- 分包已取消，所有书都在主包；自藏书仍用 USER_DATA_PATH 的 readFile（该场景官方支持）
- 加书方法更新：往 F 盘根目录放新 txt → 在 `tools/build_books.js` 的 BOOKS 里登记 → 项目目录运行 `node tools/build_books.js` → 在 `utils/books.js` 的 list 里加条目（注意主包 2MB 上限）
## v9：导入支持常见电子书格式（含 PDF）
- 文件导入**不再限制格式与大小**（此前仅 txt/5MB）：微信聊天里发的任何文件都能选
- **PDF / Word / Excel / PPT**：保存后由微信内置阅读器（wx.openDocument）打开，支持分享菜单
- **EPUB**：内置解析器（fflate 解压 → spine 顺序提取正文 → 自动生成【章节】目录），无需网络
- **TXT / 文本类**：原有阅读器；非 UTF-8 仅温柔提示、不拦截
- 未知格式（mobi 等）按「other」保存，打开时交给微信阅读器尝试
- 书架与「我的书籍」列表会显示格式标签（pdf/epub/txt/…）
- 说明：文件实际受微信聊天文件大小与手机存储（USER_DATA_PATH 约 200MB 配额）约束；开通云开发后正文自动备份云存储
