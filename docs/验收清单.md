# 「灯下读书」小程序验收清单

> 照着勾一遍，全过 = 可以正常使用。项目目录：`F:\新建文件夹 (2)\读书小程序`

## A. 环境准备
- [ ] 安装微信开发者工具（https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html）
- [ ] 微信扫码登录开发者工具
- [ ] 导入项目：目录选 `F:\新建文件夹 (2)\读书小程序`，AppID 填 `touristappid`（游客模式）或「测试号」
- [ ] 编译成功，无红色报错

## B. 书架页
- [ ] 顶部显示「今日已读 X 分钟 · 连续 X 天」
- [ ] 「每日一句」卡片正常，点「立即读书」进入对应古籍
- [ ] 读过一本书后，出现「接着读」卡片，点「继续读书」能回到上次位置
- [ ] 搜索框输入「论」，列表实时过滤出《论语注疏》
- [ ] 「＋ 导入自己的书籍」能进入导入页

## C. 阅读页
- [ ] 任一本书点「立即读书」→ 正文正常显示，无报错
- [ ] 顶部实时显示「当前章节 + 百分比 + 进度条」，滚动时更新
- [ ] A- / A+ 字号调节生效；夜间模式切换正常（底色变深色）
- [ ] 「目录」面板打开：当前章节高亮，点击条目可跳转
- [ ] 长按任意段落 → 选「复制本段」→ 到别处粘贴验证成功
- [ ] 长按段落 → 「添加书签」→ 「书签」页签可见，长按书签可删除
- [ ] 退出阅读页再进入 → 自动恢复到上次进度
- [ ] 分包里的书（《庄子》《古文观止》《世说新语》等）能正常打开（首次会静默下载分包）

## D. 我的页
- [ ] 未登录时顶部显示「未登录 + 微信登录」按钮
- [ ] 点「微信登录」→ 登录页 → 勾选协议 → 一键登录 → 完善昵称头像 → 回到我的页显示头像昵称
- [ ] 我的页点头像可换头像、点昵称可改名（即时生效）
- [ ] 「退出」有确认弹窗，退出后回到未登录态
- [ ] 统计四项数字合理；近 7 天柱状图随阅读变化
- [ ] 「本月打卡」日历：当天读满 1 分钟后，今天的格子点亮
- [ ] 「每日阅读提醒」开关可切换（未配模板时弹说明）

## E. 登录页
- [ ] 未勾选协议点登录 → 弹出「请先阅读并同意协议」
- [ ] 《用户协议》《隐私政策》两个链接能打开对应页面
- [ ] 「暂不登录，先逛逛」可跳过登录正常使用

## F. 导入自己的书籍
- [ ] 「从聊天文件中选择」→（模拟器里直接选电脑上的 txt）→ 成功入书架并可打开阅读
- [ ] 放一个 GBK 编码的 txt 导入 → 弹「编码不是 UTF-8」提示
- [ ] 「粘贴文本成书」→ 填书名 + 正文 → 保存 → 出现在「我的书籍」
- [ ] 自藏书在书架长按、或在我的页点「删除」→ 确认后移除

## G. 真机预览
- [ ] 用「测试号」AppID → 点「预览」→ 手机微信扫码打开
- [ ] 手机端：翻页流畅、字号/夜间正常、真机登录授权头像昵称正常

## H. 云同步（可选，开通云开发后）
- [ ] 我的页状态显示「已开启云端同步」
- [ ] 换一台设备登录同一微信 → 进度 / 书签 / 统计一致
